# Кроссворд: мемы и поп-культура

Браузерная словесная игра: 100 вопросов про мемы, интернет-сленг, игры, кино,
аниме, музыку и литературу. Вопросы перемешаны — никаких тематических
разделов, все темы идут вперемешку.

Десять уровней по 10 слов. Часть слов не помещается в сетку и показывается
отдельным блоком «Дополнительные слова» — их тоже нужно решить, чтобы пройти
уровень.

**Играть онлайн:** https://azaliavalieva348-cyber.github.io/crossword-memes/
**Репозиторий:** https://github.com/azaliavalieva348-cyber/crossword-memes
**Админка (переключение на любой уровень):** https://azaliavalieva348-cyber.github.io/crossword-admin/

## Что нового в этой версии

- Нежно-розовое оформление вместо тёмно-фиолетового; фон спокойный,
  без ярких пятен.
- Уровни собраны из перемешанных вопросов, без деления по темам.
- На каждый уровень даётся **4 попытки**. Каждая неверная проверка слова
  списывает одну попытку.
- Когда попытки закончились, игрок попадает на мини-игру **судоку 4×4**
  с правилами рядом. Головоломок шесть, и одна и та же подряд не выпадает.
  Собрав судоку, игрок возвращается на тот же уровень кроссворда с новыми
  попытками.
- У вопросов 10, 12, 15, 72, 78 и 81 особая подсказка: вместо буквы
  открывается плашка с пояснением.
- Перед судоку показывается баннер: несколько ошибок подряд — чтобы
  продолжить, нужно решить небольшую судоку.
- Отдельная админка (второй сайт) позволяет переключаться на любой уровень
  для проверки.
- Звук включён по умолчанию, выключается в настройках; на стартовом экране
  есть быстрая кнопка звука.
- Переключаться между уровнями нельзя: следующий открывается только после
  прохождения текущего, а пройденные уровни можно пересматривать.
- На главной появилась информационная плашка для игроков.

## Как играть

1. Выберите слово в сетке — вопрос появится в карточке.
2. Вводите буквы с клавиатуры или экранными клавишами.
3. Слово проверяется автоматически, когда все клетки заполнены, или по
   кнопке «Проверить».
4. Ошибка списывает попытку. Их четыре на уровень.
5. Если попытки закончились — соберите судоку 4×4 и вернитесь к кроссворду.
6. Когда все 10 слов уровня разгаданы, открывается следующий уровень.
7. На уровень даётся 4 подсказки — каждая открывает одну букву.

Ответы сравниваются без учёта регистра, пробелов, дефисов и разницы между
«ё» и «е».

## Уровни

| Уровень | Вопросов | В сетке | Дополнительно |
|---------|----------|---------|----------------|
| 1–10    | по 10    | 9–10    | остальные слова (вне сетки) |

На некоторых уровнях часть слов (например, длинные или цифровые «1984»)
не помещается в сетку и выносится в блок «Дополнительные слова». Они должны
быть решены, чтобы пройти уровень.
Они не мешают пройти уровень и не входят в счётчик прогресса.

## Запуск локально

```text
multitool-node tools/serve.cjs
```

Затем откройте `http://localhost:8123`. Подойдёт и любой другой статический
сервер: `npx serve .` или `python -m http.server 8080`.

Игру лучше открывать по HTTP, а не через `file://`.

## Публикация на GitHub Pages

Игра уже опубликована и обновляется автоматически при каждом пуше в ветку
`main`.

Обновление уровней:

```
git add -A
git commit -m "Обновление уровней"
git push
```

GitHub Pages пересоберёт сайт за минуту. Ссылка не меняется, поэтому прогресс
игроков в `localStorage` сохраняется: он привязан к домену, а не к версии
файлов.

## Деплой на Vercel

Проект статический, сборка не нужна: Vercel просто раздаёт папку.

**Вариант 1 — без командной строки (самый простой):**

1. Зарегистрируйтесь на [vercel.com](https://vercel.com) (бесплатный план).
2. Откройте [vercel.com/new](https://vercel.com/new).
3. Перетащите папку `modern-crossword` целиком в окно загрузки.
4. Framework Preset — «Other», Build Command оставьте пустым,
   Output Directory — корень.
5. Нажмите **Deploy**. Через минуту получите ссылку вида
   `https://ваш-проект.vercel.app`.

**Вариант 2 — через CLI:**

```text
npm i -g vercel
cd modern-crossword
vercel
vercel --prod
```

Первая команда `vercel` попросит войти в аккаунт в браузере.

**Обновление уровней.** Замените файлы в папке проекта и задеплойте снова
(перетащите папку или выполните `vercel --prod`). Ссылка останется прежней,
поэтому прогресс игроков в `localStorage` сохранится: он привязан к домену,
а не к версии файлов. Не меняйте id старых вопросов и ключ сохранения —
иначе прогресс «съедет».

В `vercel.json` отключено агрессивное кэширование `js` и `styles.css`,
чтобы после обновления игроки получали свежую версию.

## Печатная версия

Рядом с проектом лежит файл `кроссворд-вопросы-и-сетки.html` — все вопросы,
пустые сетки и ответы для печати. Он собирается из тех же данных:


## Проверки

```text
multitool-node tools/check.cjs
```

Скрипт проверяет уникальность id, непустые вопросы и ответы, отсутствие
одинаковых ответов, сборку всех уровней, совпадение букв в клетках и
детерминированность сеток.

Текущий результат: 10 уровней, 98 слов в сетках, 2 вне сеток, ошибок нет.

Браузерные проверки (изолированный Chromium, 1440×900 и 390×844):

- запуск игры и переход на первый уровень;
- ввод букв через экранную клавиатуру;
- четыре неверные проверки → переход на судоку;
- открытие судоку с одной из шести головоломок (сетка и статус на месте);
- особая подсказка вопроса 15: плашка «название фильма», счётчик подсказок
  уменьшается;
- отсутствие ошибок в консоли и горизонтальной прокрутки.

Не проверялось: реальные мобильные устройства, Safari, настоящий SDK
Яндекс Игр и реклама.

## Контент

Вопросы и ответы взяты из авторского списка без изменения формулировок.
Ответы приведены к нижнему регистру; латиница заменена кириллицей
(`Prada` → `прада`). Спорное написание «испански» оставлено как в исходнике.
Внутренние примечания хранятся в поле `note` и игроку не показываются.

Названия игр, фильмов и персонажей используются как текстовые подсказки;
сторонние изображения и логотипы не применяются.

## Известные ограничения

- В списке 100 вопросов: 98 уходят в сетки, ещё 2 — в блок дополнительных
  слов (обязательны для прохождения уровня).
- Прогресс хранится только в браузере и не синхронизируется между
  устройствами.
- SDK и реклама выключены по умолчанию; на Vercel они не нужны.
- Деплой на Vercel требует авторизации в вашем аккаунте — из этой среды
  его выполнить нельзя.
